# Maison Ember

A fictional portfolio concept exploring one private chef brand through two different customer strategies.

- `/` — minimal portfolio entry
- `/template-a` — cinematic private dining experience
- `/template-b` — practical personal chef booking platform

## Run locally

```bash
npm install
npm run dev
```

## Validation

```bash
npm run typecheck
npm run lint
npm run build
```

All chef profiles, menus, stories, prices, service areas, requests, and references are illustrative. Forms run entirely in the browser and transmit no data.
